# Security policy

Please do not post credentials, browser profiles, settings exports, personal images, or private logs in issues. A useful issue report should include the extension version, browser version, reproduction steps, and a sanitized screenshot. Keep optional provider queries and hardware identifiers out of public reports unless you intend to share them.

The extension's intended source origins and permissions are listed in its manifest and README. No external service should ever need a GitHub token or a payment credential to run this extension.
