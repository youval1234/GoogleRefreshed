# Changelog

## 1.1.0 — 2026-10-27

First release of GoogleRefreshed.

- Google-style search suggestions with mouse and keyboard selection, a 250 ms debounce, and cancellation of stale requests.
- 16 themes, independent light/dark/system modes, accent colors, background photos, and optional ambient animation.
- Official service icons, Personal/Work/Study shortcut groups, and Ctrl+K command palette.
- Optional clock and focus note.
- Automatic approximate weather location, manual city search, clear SVG conditions, and a five-day forecast.
- Local news, regional editions, topics, BBC/Guardian photo feeds, and image toggles. Google News uses placeholders because its RSS feed has no thumbnails.
- Settings import/export and a link to the private GitHub releases page.
- Bounded on-demand caches, a sleeping event-driven worker, reduced-motion support, and hidden-tab animation/clock pausing.

Validation: 35 controlled Brave checks plus live Google autocomplete, weather, and local-news smoke tests. Brave privacy settings are unchanged. Automatic browser toolbar palette syncing is not supported. Updates and unpacked installation are manual.
